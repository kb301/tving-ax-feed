# tving-ax-feed

티빙 마케팅 AX 앱의 **매일 자동 수집 데이터 피드**입니다.

- 매일 오전 7시 43분(한국 시간) 자동 수집 작업이 새 배치를 `feed/` 에 올립니다.
- 내려받은 HTML 앱이 열릴 때 `feed/index.json` 을 읽어 새 배치만 받아 분석에 합칩니다.
- 공개 웹문서(앱 리뷰·커뮤니티·블로그·뉴스)와 AI 분석 라벨만 들어 있습니다. 회원 데이터·메시지·보고서·실행 과제는 올리지 않습니다.

| 파일 | 내용 |
|---|---|
| `feed/index.json` | 배치 목록, 마지막 수집 상태 |
| `feed/batches/<배치ID>.json` | 배치별 수집 글과 라벨 |
| `feed/reviews.json` | AI·담당자 검수 결과(검수자 이름은 '담당자'로 표시) |
